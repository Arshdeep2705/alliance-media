# Alliance Media Pty Ltd — official website

Static site (no framework, no build step) for Alliance Media Pty Ltd, Melbourne —
the Australian sister company of Alliance Productions India LLP.

- `index.html` — home (hero, studio, Echoes of Us feature, slate, leadership, CTA)
- `films/echoes-of-us/` — flagship film page
- `slate/` — projects in development (Kabuliwala, Misfired, Defiant Nadia, Khoj)
- `people/deepak-tijori/`, `people/arshdeep-singh/` — leadership profiles
- `contact/` — contact page
- `styles.css` / `script.js` — shared design system + interaction layer (vanilla)

Design: obsidian black + champagne gold, Cinzel / Cormorant Garamond / Jost.
All paths are relative (works at any subpath, e.g. GitHub Pages project sites).
